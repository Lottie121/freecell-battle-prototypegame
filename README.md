# 空当接龙战斗原型 (FreeCell Battle)

一款把**经典空当接龙**和**回合制战斗**揉在一起的单文件网页小游戏。

你要做的还是接龙该做的事——把 52 张牌按花色、点数整理好送进回收区；但这一次，每收回一张牌都会变成一次攻击、治疗或增益，而对面那个"污染体"会不断往你的牌桌上泼脏水。**在一局牌打完之前，先把敌人耗死，或者别让自己先倒下。**

- 零依赖、零构建：一个 `.html` 文件双击即玩
- 纯原生 JavaScript + DOM，没有框架、没有打包工具
- 每一局都从**经过求解器验证的种子**里抽取，保证有解

## 立即游玩

### 方式一：直接打开（最简单）

下载仓库里的 `index.html`，用浏览器（Chrome / Edge / Firefox / Safari）打开即可，无需任何环境。**电脑和手机都能玩**——页面会按屏幕宽度自动等比缩放，手机上会自动切到小屏布局。

### 方式二：本地起个服务

```bash
# 在项目目录下任选一条
python -m http.server 8000
# 或
npx serve
```

然后访问 `http://localhost:8000/`。

### 方式三：GitHub Pages（把链接发给网友用手机玩）

根目录只有 `index.html`（Pages 约定的首页文件名），所以部署完成后**根网址本身就是游戏**，手机点开即玩。

在仓库 **Settings → Pages** 里配置：

- **Source**：`Deploy from a branch`
- **Branch**：`main` + **Folder** 选 **`/ (root)`**
- 点 **Save**，等一两分钟

然后访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

> ⚠️ Folder 那个下拉框**只有 `/ (root)` 和 `/docs` 两个选项，不能手动输入**，所以游戏文件必须放在仓库根目录或 `docs/` 目录下。本项目用的是 `/ (root)` + 根目录的 `index.html`。

> 📱 手机竖屏会弹出「请横屏」提示，转到横屏即可获得完整牌桌视野。

## 怎么玩

### 一、先把牌摆明白（空当接龙部分）

牌桌由三部分组成：

| 区域 | 数量 | 作用 |
| --- | --- | --- |
| 牌列 | 8 列 | 发牌区，也是主要活动区域 |
| 调度槽 | 4 个 | 临时中转，每槽只能放 1 张牌 |
| 回收区 | 4 个 | 每种花色一个，**严格按 A → 2 → … → K 顺序**堆放 |

**搭牌规则**：一张牌只能压在"点数正好大 1"且"暖冷交替"的牌上。

- 暖色组：🔥 火、⚡️ 雷
- 冷色组：💧 水、🍃 木

> 例：💧水 4 可以压在 🔥火 5 或 ⚡️雷 5 上（点数小 1、暖冷交替）；
> 但不能压在 💧水 5 或 🍃木 5 上（同组，不交替）。

**整组移动上限**（标准空当接龙公式）：

```
可移动牌数 = (空闲调度槽数 + 1) × 2^(空列数)
```

超出上限的整组牌搬不动，引擎会给出提示。

**快捷操作**：双击一张牌，会优先尝试放进它对应的回收区；放不进去，则尝试放进空闲的调度槽。

### 二、再把敌人打明白（战斗部分）

每回收一张牌，就结算一次该花色的效果：

| 花色 | 回收效果 |
| --- | --- |
| 🔥 火 | 对敌人造成等于点数的伤害 |
| 💧 水 | 回复约点数一半的血量；**血量已满或治疗溢出时，多余部分转为防御** |
| ⚡️ 雷 | 造成约点数一半的伤害，并让**敌人下次攻击减半** |
| 🍃 木 | 永久成长 +1，成长值会加成所有花色的回收效果 |

**金币**：回收任意牌都会获得等于其点数的金币。当某个花色已经收到 8（谐音"发"）之后，该花色从第 9 张起，每张回收额外 +1 金币。

**连击**：连续回收可以叠加倍率（第 1 张无加成，之后每层 +25%，最高 ×2.5）。非回收移动、撤回、结束回合都会打断连击。

**闪卡 ✦**：约 14% 的牌是闪卡，回收效果更强（火 +5 伤害、水 +4 治疗并冰冻敌人、雷伤害翻倍、木成长 +2）。

**净化**：被敌人污染过的牌会打上紫色标记，回收这张牌时获得额外加成（+2）。

### 三、资源与回合

| 资源 | 数值 | 说明 |
| --- | --- | --- |
| 血量 | 30 | 归零即失败 |
| 魔力（蓝条） | 15 | 开局 8 点，每回合回复 3 点 |
| 防御 | 上限 10 | 受击时优先由防御抵扣 |
| 成长 | — | 由 🍃 木牌累积，永久加成 |
| 金币 | 开局 50 | 用于商店买道具 |

**回合机制**：每回合的移动次数在 6~10 之间随机浮动，**敌人在回合开始前会预告**下一回合的攻击力、移动次数和污染手段。步数用完自动进入下一回合；也可以点顶栏的「**结束回合**」按钮主动结束。

**魔力可以这样花**：

- 撤回上一步（1 点魔力，可无限次；撤回会连带回滚这步造成的金币/伤害/道具消耗）
- 本回合额外多走一步（2 点魔力）
- 回溯到本回合开始的状态（10 点魔力 + 1 点成长）
- 消耗 1 点血量换 2 点魔力

**开局福利**：正式开局前 120 秒为无限移动（落位不消耗步数），并自带 1 个「大力移动」道具、50 金币。

### 四、敌人会怎么恶心你

敌人的"污染"**只做可恢复、且牌面总量守恒的干扰**，不会制造死局：

| 污染手段 | 效果 |
| --- | --- |
| 锁牌 | 锁住一张牌 2 回合，期间不能移动 |
| 换花色 | 两张牌互换花色 |
| 换点数 | 同花色的两张牌互换点数 |
| 冻结调度槽 | 冻结一个空调度槽 2 回合 |

被污染过的牌会留下紫色标记，回收时给你净化加成作为补偿。

### 五、道具

道具牌夹在牌列里，**挖到最上面后点击即可收进背包**。背包里的道具点一下就能用：

| 道具 | 效果 |
| --- | --- |
| 🧪 治疗药剂 | 回复 8 点血量 |
| ⏳ 时间禁锢 | 冰冻敌人 2 回合 |
| 🗝 万能钥匙 | 解除全部锁定与冻结 |
| 🔄 临时调度槽 | 增加一个额外调度槽（不影响可移动牌数） |
| 💪 大力移动 | 获得 1 层充能，启用后整组移动无视上限 |
| 🧿 回蓝药剂 | 回复 4 点魔力 |
| 🔁 任意交换 | 点选场上任意两张牌，交换它们的位置 |
| ♾ 无限移动 | 30 秒内落位不消耗移动次数 |
| 🪂 强制降落 | 把任意一张牌（含被压住的）强行送进空闲调度槽 |
| 🛡 护盾符 | 立即获得 6 点防御 |
| 🎲 预知 | 重掷敌人下回合的污染预告 |

**商店**：花 5 金币可以直接买「大力移动」，或花 5 金币抽一个随机道具。抽卡/埋牌只会出上面这些普通道具。

**条件奖励道具**（金色高亮，达成条件自动进背包，每件每局只发一次，不会随机抽到）：

| 道具 | 触发条件 | 效果 |
| --- | --- | --- |
| 🧹 洗牌 | 清空一整列 | 把牌列里剩余未回收的牌重新洗一遍再发 |
| ⏱ 时间暂停 | 一回合内连击达到 5 | 敌人下一次行动被跳过 |
| 🎯 定点狙击 | 某个点数的 4 张全部回收 | 直接对敌人造成 10 点伤害 |
| 🌪 龙卷风 | 同时空出 4 个调度槽（且用过调度槽） | 把某张牌及其下方整摞牌搬到另一列，无视移动上限 |
| 📦 补给箱 | 把牌列里的道具牌全部挖出来 | 立刻再抽 2 件随机道具 |
| ⏳ 蓄力 | 剩余步数 ≥ 8 时主动结束回合 | 下回合移动次数 +3 |
| 💎 完美主义 | 本局一次没撤回就走满 10 回合 | 立即获得 15 金币 |

> 「👑 王冠」由原有的「发」机制承担：某花色从 A 一路收到 8（谐音"发"）后，该花色此后每张回收额外 +1 金币。

### 六、胜负条件

- **胜利**：4 个回收区全部收满到 K，或把敌人（100 点血）打倒
- **失败**：血量归零，或牌局陷入无可移动的死锁

### 七、操作提示

- **按住拖动**：把符合规则的一组牌拖到目标位置；松手后会自动吸附到附近能放的位置
- **双击**：快速回收 / 放入调度槽
- **长按一张牌约 0.5 秒**：弹出该牌的效果说明
- **拖动时**：可接收的合法目标会亮**绿色**；点数对得上、但当下还落不下去的目标会亮**橙色脉冲**（比如整组超出移动上限或被锁住）
- **教程**：开局会自动弹出新手教程，顶栏的「教程」按钮可随时重看

## 技术栈

- **HTML5 + CSS3 + 原生 JavaScript（ES5/ES6 混合，无框架、无依赖、无构建）**
- 全部代码集中在单个 `.html` 文件内（内联 `<style>` + 内联 `<script>`）
- 渲染基于 **原生 DOM API**，牌的拖动使用 **Pointer Events**，拖动中的牌放在独立的 `#drag-layer` 图层
- 布局使用 **Flexbox**，异步回收动画使用 CSS transition
- 移动端适配方案：用 `#stage` 包裹游戏主体，通过 `transform: scale()` **等比缩放**整个舞台，并对拖动层做缩放补偿（位移与吸附阈值同步换算）
- 牌局随机性使用 **线性同余伪随机数（LCG）**，同一个种子必然还原出同一副牌

### 关于"保证可解"

`SOLVABLE_SEEDS` 里收录了 13 个种子，**每个种子对应的牌局都事先用离线求解器实际求解过**，网页端再用同一套 LCG 算法重现洗牌。因此每次开局随机抽到的牌局都是有解的，不存在死局开局。

## 自定义与调参

所有可调参数都集中在脚本顶部的 `CONFIG` 对象里（血量、魔力、回合步数、闪卡概率、污染权重、金币规则等），改完刷新页面即生效，无需重新构建。

例如：

```js
const CONFIG = {
  playerMaxHp: 30,              // 玩家血量上限
  enemyMaxHp: 100,              // 敌人血量上限
  movesMin: 6, movesMax: 10,    // 每回合移动次数区间
  manaStart: 8, manaRegen: 3,   // 开局魔力 / 每回合回蓝
  goldStart: 50,                // 开局金币
  openingInfiniteSeconds: 120,  // 开局无限移动秒数
  // ...
};
```
